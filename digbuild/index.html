Instructions: Use the WASD keys to move around, you start with the hands item. Use the number keys along the top of the keyboard to change what thing you are holding. Place the item by right clicking. Use the item by left clicking. Start by digging When you dig dirt, there is a chance you will get gravel instead. You can hit gravel with gravel a bunch ( some items you use a lot by holding the button longer,others you use a lot by clicking a bunch) to get sharp rocks. You can use sharp rocks to harvest logs, which will sometimes give a building table instead. Use items that need to be placed first by right clicking on them once they are placed. Branches grow over time. You can build a shovel, axe, weapon, and pickaxe. Monsters appear in the dark. Get string by defeating spiders. You can use a bow on sticks to start a fire
